# Getting started

## Choose an accelerator

The [accelerator catalog](../README.md#accelerators) lists every accelerator with its sector
and technologies.

## Before you deploy

Each accelerator README lists:

- the scenario and the problem it solves;
- the architecture and Microsoft services it uses;
- prerequisites, such as licenses, capacities, permissions and tools;
- expected cost drivers;
- known limits.

Accelerators deploy into your own Microsoft tenant and subscription. Microsoft does not host or
operate them for you.

## Deploy

Follow the guide in the accelerator's `deploy/` folder. Use the synthetic sample data first,
validate the result, and then connect your own data sources.
