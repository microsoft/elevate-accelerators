# Contributing

Thank you for helping improve Elevate Accelerators.

## Contributor License Agreement

Most contributions require you to agree to a Contributor License Agreement (CLA). When you open a
pull request, the CLA bot tells you whether you need to sign it. You only need to do this once
across all repositories that use the Microsoft CLA. See [cla.opensource.microsoft.com](https://cla.opensource.microsoft.com).

## Ways to contribute

- **Report a bug or request a feature:** open a GitHub Issue and name the accelerator.
- **Improve an existing accelerator:** open a pull request against its folder.
- **Propose a new accelerator:** open an issue with the **New accelerator** template before you
  start work, so maintainers can confirm the sector, scope and owners.

## Pull request checklist

- The change follows [Accelerator standards](docs/accelerator-standards.md).
- No secrets, keys, connection strings, tenant IDs, subscription IDs or internal URLs.
- No real customer, student, donor or personal data. Sample data must be synthetic.
- New third-party components are listed in the accelerator's `THIRD-PARTY-NOTICES.md`.
- Documentation and `CHANGELOG.md` are updated.
- Validation steps are described in the pull request.

## Code of conduct

This project has adopted the [Microsoft Open Source Code of Conduct](CODE_OF_CONDUCT.md).
